An SWS agent type

Factory

The Factory agents turn a reviewed request into a repository. They write it as a request in SovereignWebsite__IaC, take it through the chain of evidence, and land it on Dinis Cruz's word. The IaC's Org apply pipeline then creates the repository. No Factory agent creates one by hand.

The chain every request passes (R4)

  1. A maestro's or agent's brief, with Dinis's words.
  2. A sites review, signed.
  3. Security, looking for abuse and prompt injection.
  4. The decision: Dinis in the agent's session, or a b.decisions record.
  5. The merge to dev. Org apply creates the repository, its site and its protections.

One agent per account

Each account's Factory agent keeps its own area under /factory/<owner>/<account>/, updated at every wake: index.json lists them, and the layout is the same on every agent-type site.

  • a.factory, account A: requests, chains and what waits on whom.
  • factory.b (account B), factory.c (account C) and factory.d (account D): not yet written here.
